# Аналіз обласних часових рядів

Вкладка: **Аналітика → Складові ряду**. Типовий приклад — Львівська область,
січень 1960 — грудень 2025. Доступні температура, опади, вологість і вітер;
область обирається на карті або пошуком. Доступний кінець інтервалу обмежено
останнім повним місяцем з урахуванням семиденної затримки ERA5.

## Дані

ECMWF ERA5 через [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api),
CC BY 4.0, UTC, фіксована модель `era5`. Використано координати з
`scripts/fetch_weather.py`: одна опорна точка для кожної з 27 адміністративних
територій України. Це реаналіз поблизу міста, **не площинне середнє області і не
спостереження обласної метеостанції**. Географічне узагальнення на всю область
потребувало б окремого зважування сітки в адміністративному полігоні.

Температура, вологість, вітер — середні добових значень повного місяця;
опади — сума добових значень повного місяця. Неповний місяць має пропуск.
Пропуски не заповнюються й не перетворюються на нулі. Для 2000–2025 повторно
використовується наявний CSV; старші десятиліття й нові місяці завантажуються
з API та кешуються в `data/regional_history/` разом із URL і датою отримання.

Для завантаження всіх областей наперед:

```powershell
.\.venv\Scripts\python.exe scripts/fetch_regional_history.py --end 2025-12
```

Параметр `--wait-for-quota` дозволяє автоматично продовжувати після скидання
погодинного ліміту. Локально запущений прихований завантажувач пише стан у
`logs/regional-history.log`, помилки — у `logs/regional-history-error.log`,
PID — у `logs/regional-history.pid`. У разі ліміту API сайт повідомляє про нього
і пропонує обрати локальний період 2000–2025; частково завантажені старі роки
не видаються за повну історію.

## Модель

Адитивна модель `Y_t = T_t + S_t + C_t + E_t` придатна також для від'ємних
температур і нульових опадів. Це ретроспективний опис, не прогноз.

1. Згладжена тренд-циклічна компонента:
   `M_t = (0.5 Y_(t−6) + sum(Y_(t+j), j=−5…5) + 0.5 Y_(t+6))/12`.
2. Для кожного календарного місяця обчислюється середнє `Y_t−M_t`.
   Із дванадцяти середніх віднімається їх спільне середнє: `sum(S_m)=0`.
3. `T_t = a + b t` — МНК-регресія доступних `M_t` на час у роках.
4. `C_t = M_t−T_t` — відхилення згладженого рівня від лінійної тенденції.
5. `E_t = Y_t−M_t−S_t` — залишкова, умовно випадкова компонента.

Перші та останні шість місяців не мають `M`, `C`, `E`. За наявності пропуску
центрована оцінка не будується для всього вікна, яке його містить. Трендова
лінія показана в межах обраного періоду, без прогнозу за його межі.

Розділення тренду й циклу **не є унікальним**: воно залежить від припущення про
лінійний тренд і згладжування. Знак `C` не доводить наявність періодичного
кліматичного циклу. Залишок може мати автокореляцію; він не оголошується білим
шумом. Випадкові числа до спостережень не додаються. Нахил за десятиліття
дорівнює `10b`; довірчі інтервали і статистична значущість не обчислюються.

## Порівняння місяців

Для кожного із 12 календарних місяців подано кількість доступних років,
середнє, середні раннього й пізнього непересічних періодів, різницю та окремий
МНК-тренд за десятиліття. Довжина кожного порівнюваного періоду — менше з
30 років і половини кількості календарних років у вибірці. Для 1960–2025 це
1960–1989 та 1996–2025. Для опадів це середні **місячні суми**, а не середня
добова інтенсивність. Доступні кількості місяців повертаються API; для неповних
років періоди можуть мати різне число спостережень.

### Автокореляція залишків

Для лагів `k=1,…,24` показано вибіркову оцінку
`r_k = sum((E_t−mean(E))*(E_(t−k)−mean(E))) / sum((E_t−mean(E))^2)`.
У чисельнику використовуються тільки наявні календарні пари з відстанню
рівно `k` місяців; знаменник і середнє — спільні для всіх лагів. API також
повертає кількість пар. За нульової дисперсії чи відсутності пар значення
невизначене. Це вибіркова реалізація одновимірної автокореляції, а не
буквальна копія багатовимірного запису (4.1). Межі значущості й висновок
про білий шум автоматично не будуються.
